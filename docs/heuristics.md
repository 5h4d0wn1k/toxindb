# Heuristics

toxindb implements 12 detection heuristics (TX-001 through TX-012) for retrieval-time poisoning detection:

- TX-001: Demand Concentration
- TX-002: Recency Anomaly  
- TX-003: Embedding Cluster
- TX-004: Canary Resurgence
- TX-005: Provenance Mismatch
- TX-006: Bulk-Ingest Pulse
- TX-007: Query-Doc Mismatch
- TX-008: Double Retrieval
- TX-009: Source Cartel
- TX-010: Drifted Authority
- TX-011: New-Namespace Flash
- TX-012: Quarantine
