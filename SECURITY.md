# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in toxindb, please report it responsibly:

1. **Do NOT** open a public GitHub issue for security vulnerabilities.
2. Email security details to: 5h4d0wn1k@users.noreply.github.com
3. Include: description, reproduction steps, impact assessment.
4. Allow reasonable remediation time before public disclosure.

## Scope

toxindb is a **defensive, offline** security analysis tool. It makes no network
calls and operates entirely on local trace files. The primary security concern is
correctness of detection heuristics, not attack surface.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |
